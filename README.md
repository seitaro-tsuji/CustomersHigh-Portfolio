## ゲーム概要
自動で走り続けるキャラクターを操作して、ゴールを目指す2Dランアクションゲームです。

メインステージの前に強化アイテムがランダムに配置された準備エリアが設置されており、自分好みにステータスをカスタマイズしてメインステージクリア時に高スコアを目指します。

最高スコアは記録され、タイトル画面のステージ選択時に表示されます。

## 操作方法
【PC版】
- Spaceキー：ジャンプ
- 画面内の特殊アクションボタンをクリック：特殊アクションの発動

【Android版】
- 画面タップ：ジャンプ
- 画面内の特殊アクションボタンをクリック：特殊アクションの発動

## 工夫した点
スマートフォンでのプレイも想定しているため、単純な操作で奥深いゲームを目指しました。その結果、必要な操作は上述の2通りのみとなりました。

また、リプレイ性を上げるため、準備エリアの配置アイテムや地形をランダムで生成するようにしました。

配置されるアイテムは以下の通りです。

- ステータスアップアイテム
  - HPアップ
  - スピードアップ
  - ジャンプ力アップ
    
- 特殊アクション解放アイテム
  - ダッシュ
  - 空中ジャンプ
  - ファイアボール
  - 画面内全アイテム取得

後述する方法で最終スコアがランク付けされますが、全てのステージ、全ての特殊アクションで最高ランクを取得できるように調整しました。
 
さらに、高スコアを目指して何度もプレイするため、ステージ画面・リザルト画面内にリプレイボタンを配置してすぐにステージをやり直せるようにしました。

## 特殊アクション
実装した特殊アクションは以下の通りです。

- ダッシュ
  - ボタンを押している間、ゲージを消費して走る速さが2.5倍になる
  - ゲージはボタンを離している間に回復する
    
- 空中ジャンプ
  - 空中でも1回までジャンプを使用できる
  - 着地すると再度空中ジャンプを使用できる
    
- ファイアボール
  - 前方にプレイヤーよりも速く飛ぶ火の玉を出す
  - この能力によってのみ敵キャラクターを撃破できる
  - 画面内に2つあるときは生成できない
    
- 画面内全アイテム取得
  - 画面内のすべてのコインを回収できる
  - 1回のみ使用可能

## 準備エリアのランダム生成
区画のPrefabを複数用意して、それらをルールに従って順に配置するという方法で準備エリアをランダム生成しています。

地形そのものを完全にランダム生成すると、プレイヤーが到達できない配置やゲーム性を損なう配置が発生しやすいため、あらかじめゲームが成立する区画をPrefabとして設計しておき、その組み合わせと順番をランダム化する方式を採用しました。

各区画にはTierを設定しています。Tierは主にアイテム取得に要求されるジャンプ力の指標であり、Tierが高い区画は後半に配置するように区画生成ルールを設定しました。

また、特殊アクション解放アイテムは必ず準備エリアの最後に配置されるように実装しました。

準備エリアの途中で「画面内全アイテム取得」を入手すると、それ以降のアイテム選択を無視して大量取得が可能になるため、特殊アクションの取得タイミングを最後に固定することでゲームバランスを保っています。

## 最終スコアの計算とランク付け
ステージクリア時のスコアは、以下の要素から計算されます。

- 集めたコインの枚数
  - (枚数×100)ポイント
  - 「空中ジャンプ」や「画面内全アイテム取得」を取得すると高くなります。
    
- クリアまでの秒数
  - (8000－秒数×200)ポイント  (下限は0ポイント)
  - 「ダッシュ」を取得すると高くなります。
    
- ダメージを受けた回数
  - (2000－回数×500)ポイント 　(下限は0ポイント)
  - 「空中ジャンプ」を取得すると高くなりやすいです。
    
- 敵を倒した数
  - (倒した数×200)ポイント
  - 「ファイアボール」以外で敵を倒すことはできません。

以上のスコアの合計が最終的なスコアとなり、以下のようにランク付けされます。

- SSランク：10000~
- Sランク：8000~9999
- Aランク：6000~7999
- Bランク：4000~5999
- Cランク：2000~3999
- Dランク：0~1999
